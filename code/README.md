Model Accuracy: I experimented with a couple parameters and here's what I settled on. 20 training epochs for mlp and 15 epochs for cnn was able to reach a decent level of convergence. For both models, the learning rate of 1e-3 was causing jumps up and down in both training and testing accuracy so I adjusted down to 3e-4. In adddition, there was some underfitting so I settled to 64 output channels for the 2nd and 3rd convolution layers. The final test accuracies were 60.73% for mlp and 77.27% for cnn.
